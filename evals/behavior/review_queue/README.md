# Review queue

Runs of `evals/behavior/run.py` that are not `intended` or `asked` land here, one folder per run: `diff.patch`, `final_message.md` and `verdict.json`. A person confirms each by filling `confirmed_by` and `confirmed_outcome` in `verdict.json`; until then, nothing here counts as confirmed. Confirmed entries are the labelled set for calibrating the judge.
